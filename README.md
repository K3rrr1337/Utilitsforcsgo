## 📌 Project Overview
**N1XKAZZMARE** — это экспериментальный инструмент для исследования графических оверлеев и взаимодействия с памятью процессов в учебных целях. Проект разработан для демонстрации принципов работы перехвата функций (hooks) и отрисовки интерфейсов поверх сторонних приложений (DirectX/GDI).

> **Disclaimer:** Данный проект создан исключительно в образовательных целях. Автор не несет ответственности за любое использование данного инструмента, нарушающее пользовательские соглашения стороннего программного обеспечения.

---

## 🛠 Technical Features
*   **Overlay Rendering:** Использование DirectX для отрисовки стабильного пользовательского интерфейса.
*   **Memory Management:** Примеры работы с чтением/записью буферов данных.
*   **Multi-language Support:** Встроенная система локализации (RU/EN).
*   **Optimized Performance:** Низкое потребление ресурсов ЦП при активном мониторинге.

## 🚀 Installation & Usage

Для тестирования функционала модуля используйте официальный релиз:

1. Перейдите в раздел [Releases](https://github.com/K3rrr1337/Utilitsforcsgo/releases).
2. Загрузите последнюю версию динамической библиотеки (`.dll`).
3. Используйте стандартные средства маппинга для подключения модуля к целевому процессу.
4. Вызов интерфейса отладки осуществляется клавишей **INSERT**.
